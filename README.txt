Story Atelier｜安價小說集

使用方式
1. 解壓縮整個資料夾。
2. 使用瀏覽器開啟 index.html。
3. 點選右上角「管理後台」可管理作品、人物與章節／幕間。
4. 在「人物」新增人物時，可於「所屬分類」輸入或選擇分類，例如「耀晨娛樂公司」、「TrAce」。
5. 前台「人物介紹」頁面可依作品及人物分類篩選。

資料儲存提醒
目前為前端展示版，作品、人物、分類、人物立繪及回答圖片保存在目前瀏覽器的 localStorage。清除瀏覽器資料或更換裝置不會自動同步。請定期匯出公開資料並另外備份重要資料。

公開部署
管理版修改資料後，按「匯出公開資料」，將產生的 public-data.js 覆蓋到公開版 story_atelier 資料夾，再重新部署公開版資料夾。

目前導覽列：首頁、作品一覽、人物介紹、關於。
本版本已移除 BGM 上傳、播放及匯出功能；其他原有功能保留。
