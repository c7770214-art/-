Story Atelier｜閱讀導覽更新版

本次只更新公開版閱讀介面，管理版檔案與既有作品資料均維持原樣。

本次功能：
1. 每次進入章節、幕間或幕間一覽頁面，都會自動回到頁面最上方。
2. 章節閱讀頁底部新增「上一章」及「前往下一章」按鈕，可直接切換同一作品的前後章節。
3. 章節閱讀頁新增「查看本章幕間」按鈕，進入該章節的幕間列表，讀者可自行選擇要閱讀的幕間。
4. 幕間閱讀頁可返回本章幕間一覽，並可從幕間一覽返回原章節。
5. 保留已移除 BGM 的版本，不新增音樂功能。

更新方式：
- 將 story_atelier 資料夾內的 app.js 與 styles.css 覆蓋公開網站資料夾中的同名檔案。
- public-data.js 不需要更動。
- creator-tools 管理版不需要更動。
- 完成後重新部署 story_atelier 公開網站資料夾至 Netlify。
閱讀導覽：章節閱讀頁可切換上一章／下一章、查看本章幕間及返回章節目錄；幕間一覽頁可返回本章或章節目錄。
